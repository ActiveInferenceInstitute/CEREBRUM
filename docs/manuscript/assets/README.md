# Figure assets

The figure registry records the provenance of the manuscript illustrations.

The [figure source](../components/figures/) supplies editable Mermaid
definitions. The existing PNG figures are in [the historical render
directory](../../../paper/output/). A clean template build copies those
committed figures and the [figure registry](figure_registry.json) into its
working output. Regenerate figures with the [original render command](../../../paper/README.md).
